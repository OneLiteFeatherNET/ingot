# Adopters

Organisations that run Ingot are listed here, so that people who evaluate Ingot can see who already relies on it.
Being listed is not a commitment by the project or by the organisation.

| Organisation | Link | What they run |
|--------------|------|---------------|
| OneLiteFeather | [github.com/OneLiteFeatherNET](https://github.com/OneLiteFeatherNET) | Ingot |

To add an organisation, open a pull request that adds one row to the table. Give the name as it should be shown,
an optional link, and a short description of what Ingot serves. Nobody is added without such a pull request.
