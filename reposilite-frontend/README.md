# Ingot Frontend

Vue 3 dashboard, styled with [Tailwind CSS 4](https://tailwindcss.com/) and a
[Material Design 3](https://m3.material.io/) token set. Read [DESIGN.md](./DESIGN.md)
before adding styles or components.

### Running

```
# Install dependencies
$ npm install

# Run only frontend (Vite dev server on port 8888)
$ npm run dev

# Run only frontend with fake api (does not require backend)
$ npm run full
```

### Checks

```
# Unit tests (Vitest, jsdom)
$ npm run test

# Lint
$ npm run eslint

# Production build
$ npm run build
```
