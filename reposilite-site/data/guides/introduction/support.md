### I need help

If you need help,
the main channel of communication is the issues section on GitHub:

* [GitHub / Ingot :: Issues](https://github.com/OneLiteFeatherNET/ingot/issues)

Feel free to ask about anything :)

Ingot is a fork of Reposilite. A bug that also reproduces on an unmodified Reposilite build
belongs upstream, where more people can help with it:

* [GitHub / Reposilite :: Issues](https://github.com/dzikoysk/reposilite/issues)
