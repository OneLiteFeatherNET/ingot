# Get started

This section takes you from an empty machine to a running instance. The tutorials start one Ingot server with Docker, which is the `all` deploy target, where one process serves the dashboard, the API and the repositories. For the other shapes, see [Deployment options compared](../set-up/deployment-options-compared.md).
