# Release notes

Ingot keeps its release notes in three places. Use the one that matches your question.

| I want to know | Read |
|---|---|
| What changed in each version, with links to the commits and the issues | [CHANGELOG.md](https://github.com/OneLiteFeatherNET/ingot/blob/main/CHANGELOG.md) |
| The text of one release, and the files it ships | [GitHub releases](https://github.com/OneLiteFeatherNET/ingot/releases) |
| What a version number means and when it changes | [VERSIONING.md](https://github.com/OneLiteFeatherNET/ingot/blob/main/VERSIONING.md) |

The changelog is generated by the release tooling from the commit messages, as configured in `release-please-config.json`. A release is a tag of the form `vX.Y.Z` on the repository. The newest entry in the changelog is the newest release that has been tagged.

## Changes that affect an upgrade

The changelog lists every change. The effects of the changes on an upgrade are collected in [Upgrade changes and supported paths](upgrade-changes.md): the supported upgrade paths, what the first start changes in the database, the configuration, the tokens and the environment variables. Read that page before you upgrade, and then the steps in the matching upgrade how-to.
