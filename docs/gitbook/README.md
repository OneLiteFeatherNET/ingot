# Ingot documentation

Ingot is a drop-in replacement for Reposilite. The pages are split into four sections, one purpose each.

* **Tutorials** are guided lessons for a first contact. None are published yet.
* **How-to guides** show how to finish one task, such as an upgrade or a rollback.
* **Reference** lists facts to look up, such as tables of changes and supported upgrade paths.
* **Explanation** describes why things work the way they do.

To upgrade an existing installation, start with [Back up before upgrading](how-to/back-up-before-upgrading.md).
