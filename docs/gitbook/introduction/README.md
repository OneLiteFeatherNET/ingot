# Introduction

Ingot is a self-hosted Maven repository manager. It hosts, proxies and caches artifacts over the plain Maven protocol, adds users, teams, single sign on, search and an audit log, and runs as one JVM process or as several replicas on a shared database. It is a drop-in replacement for Reposilite 3.x.

This section answers what Ingot is and whether it fits. To try it, go to [Get started](../get-started/README.md).
